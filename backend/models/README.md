# Model artifacts

This directory contains generated model artifacts used by PreFlight.

## What is here

- Trained model files
- Evaluation outputs
- Model cards and summaries

## Provenance

The model is trained by the project’s local training pipeline (`backend/train_model.py`) and reflects the project’s synthetic training data and rules-based detector design.
