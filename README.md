# PreFlight

A small local AI that checks a web page for attacks on **you** (phishing, fake "verify you are human" pages, card skimmers, drive-by downloads, cryptominers, scam pop-ups) before your browser opens it.

**All documentation lives in the [`readme/`](readme/) folder.** Start with [`readme/README.md`](readme/README.md).
