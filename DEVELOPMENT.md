## Quick start for a judge

```bash
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python train_model.py
python -m unittest
python serve_demo.py
```

In a second terminal:

```bash
cd backend
source .venv/bin/activate
python run_server.py --allow-private-targets
```

Then open http://127.0.0.1:8000/ in a browser and click the demo links.

## What was built

- Local-only browser extension + Python scanner
- Static analysis of target pages without executing JavaScript
- Rule-based detectors for phishing, ClickFix, hidden iframes, cryptojacking, browser-in-the-browser, etc.
- A local ML model for probabilistic scoring and explanations
- A clear "Unsure" path when the page cannot be judged confidently

## Verification

- `python -m unittest` runs the unit and end-to-end checks.
- `python evaluate.py` runs the evaluation pipeline and compares against baselines.
- `backend/reports/` contains the generated evaluation outputs.

## Notable files

- `backend/run_server.py` — local scanner service
- `backend/serve_demo.py` — demo site and attack pages
- `backend/preflight/scanner.py` — orchestration of fetch + analysis + scoring
- `backend/preflight/detectors/` — attack detection rules
- `extension/background.js` — browser-side service worker
